## General Setting

* **Theme**: Switch between Light and Dark mode for comfortable viewing based on your environment or preference.
* **Language**: Change the interface language for a more familiar experience.
* **Render user messages as markdown**: Enable to display your messages with markdown formatting (useful for code, lists, and formatting).
* **Auto-Scroll to latest message on chat open**: Turn on to automatically jump to the most recent message each time you open a chat.
* **Hide right-most side panel**: Use this to declutter your screen if you want more focus on the main chat area.
* **Archived chats (Manage)**: Find and manage your archived conversations for better organization.

## Chat Setting

* **Message Font Size**: Adjust how large the chat text appears for better readability.
* **Chat direction (ltr/rtl)**: Set the direction for your chat input (useful for different languages).
* **Center Chat Input on Welcome Screen**: Keeps the input field centered for a clean look when you first open Doraverse.
* **Press Enter to send messages**: Enable or disable sending messages with the Enter key (handy for multiline typing).
* **Maximize chat space**: Expand your chat area for deeper focus in conversations.
* **Always show code when using Code Interpreter**: Automatically show code output when working with AI code generation.
* **Save drafts locally**: Drafts of your messages are saved on your device—great for not losing in-progress thoughts.
* **Scroll to the end button**: Quickly jump to the bottom of a long conversation.

## Speech Setting

* **Speech to Text (Simple/Advanced)**: Set up how spoken words are converted to text. Choose your preferred engine and language.
* **Text to Speech**: Choose how written text is read aloud. Customize the engine and pick a voice that fits your needs.

Use Speech options for accessibility or hands-free operation.

## Data Controls

* **Import conversations from a JSON file**: Bring in saved conversations from another file or system.
* **Shared links (Manage)**: View and manage the links you’ve shared with others.
* **Revoke all user provided credentials**: For security, quickly remove any credential you’ve provided for integrations.
* **Delete TTS cache storage**: Clear the stored voice data from your device.
* **Clear all chats**: (Be careful!) Deletes all your chat histories—use for cleanup or starting fresh.

## Account Setting

* **Display username in messages**: Decide whether your name appears when you send messages.
* **Profile Picture (Change picture)**: Upload or update your avatar to personalize your account.
* **Delete account**: Permanently remove your account if you no longer need Doraverse (irreversible).
