# ユーザーアクティビティレポート

このレポートを活用して、日々の活動状況をモニタリングし、主要ユーザーの特定やリソース配分の最適化を行いましょう。

## ユーザーアクティビティレポートの使い方

1. **期間選択**\
   日付範囲フィルターを使って希望する期間を選択します。レポートが選択期間に応じてデータを更新します。
2. **日次アクティブユーザーグラフの分析**\
   毎日AIツールを利用しているユニークユーザー数を確認できます。活動量のトレンドや急上昇・急減を把握し、導入拡大・施策の効果、あるいはエンゲージメント低下の兆候を捉えるのに有用です。
3. **ユーザー別集計テーブルの確認**\
   **チャート下部に、以下の主要指標ごとのユーザーランキングリストが表示されます。**
   * **ユーザー：**&#x30A2;クティブユーザーの氏名
   * **部門：**&#x30E6;ーザーの所属部門やチーム
   * **クレジット使用量**：選択期間内にそのユーザーが利用したAIクレジットの合計
   * **メッセージ数：**&#x41;Iモデルへの送信メッセージ件数
   * **メッセージあたりコスト：**&#x31;メッセージあたりの平均クレジット使用量
   * **前期間比較**：前回期間との比較指標。ユーザー行動の変化を可視化します
   * **トップモデル**：各ユーザーが最も頻繁に使用しているAIモデル

## 💡ヒント

* 最も活発なユーザーや利用率の低いユーザーを特定し、パワーユーザーの表彰や個別支援に活用
* クレジット使用量・コスト効率を追跡し、支出最適化の判断材料に
* 各種トレーニングや導入施策、業務プロセス変更の効果検証のため、期間ごとに傾向を比較
