# チャットログ

## チャットログとは？

チャットログは、ワークスペース内でAIモデルやエージェントと行われた全ての会話を包括的に閲覧できる機能です。\
主な活用ポイントは以下の通りです：

* ユーザーのやり取りを追跡し、説明責任や透明性を向上
* チャット内容を分析し、品質改善・コンプライアンス遵守・業務最適化を実現
* 過去の会話を簡単に検索・参照でき、コラボレーションにも役立つ
* 部門横断のチャット活動をモニタリングし、データセキュリティとガバナンスを担保

この一元管理ビューにより、管理者やマネージャーはAIを活用したコミュニケーションの全体像を把握し、業務効率化とチームの生産性向上を実現できます。

## **チャットログに含まれる情報**

* **タイトル**：会話の内容が一目で分かるタイトル
* **ユーザー：**&#x30C1;ャットを開始または参加したメンバー
* **モデル：**&#x4F1A;話を担当したAIモデル
* **時刻：**&#x30C1;ャットが実施された正確な日時
* **エージェント：**&#x30BB;ッション内で利用した特定のエージェント
