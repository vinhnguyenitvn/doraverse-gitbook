# モデル利用レポート

このレポートを活用して、パフォーマンスの監視や支出最適化、モデル選定の指針としましょう。

## モデル別レポートの使い方

1. **期間・プロバイダー・モデルによるフィルター**\
   上部のフィルター機能で、希望する期間（Time Range）、プロバイダー（Provider）、AIモデル（Model）を選択し、特定の期間・提供元・モデルに絞って分析可能です。
2. **各モデルの主要指標を確認**\
   メインテーブルでは、利用中のAIモデルごとに以下の詳細指標を表示します：
   * **モデル：**&#x41;Iモデルの名称（およびアイコン）で簡単に識別
   * **コード：**&#x30E2;デルのバージョンやコード
   * **メッセージ総数**：各モデルが処理したメッセージ件数。活用度やワークロードを可視化
   * **使用金額：**&#x5404;モデルで発生した総コスト。リソース配分状況の把握に
   * **メッセージあたりコスト**：1件あたりの平均コスト。他モデルとの効率性や価値を簡単に比較可能

## 💡 ヒント

* 各部門・タスクに最適なAIモデルを割り当て、AI利用の最適化を推進
* モデル別のコスト効率を比較し、予算策定やリソース配分の判断材料に
* 最も利用頻度の高いモデルや高コストモデルを特定し、運用改善やコスト削減策立案につなげましょう
