# 概要

## 概要ダッシュボードの使い方

1. **期間選択**\
   ダッシュボード右上のタイムレンジのドロップダウンをクリックします。\
   「今日」「昨日」「今週」「過去7日間」「過去30日間」「今月」「先月」などのプリセットから選択できます。特定の期間を指定したい場合は「カスタム」を選び、カレンダーで開始日と終了日を設定してください。\
   「適用」をクリックすると、選択した期間でダッシュボードが更新されます。
2. **主要指標の確認**
   * 総クレジット利用額：選択期間内で使用されたクレジット（支出）の合計額です。組織全体のAI関連コストを一目で把握できます。
   * 利用率：AIを積極的に利用したユーザーの割合と実際の利用者数を表示します。チーム全体での導入・活用状況の把握に役立ちます。
   * ユーザーあたりコスト：ユーザー一人あたりの平均支出額です。個別のコスト分布や効率性のトレンド分析に有用です。
   * 総メッセージ数：AIを介して送信された全メッセージ数と、メッセージ1件あたりの平均コストを表示します。活動量の把握やコスト効率性のモニタリングに活用できます。
3. **クレジット利用チャート分析で、より深いインサイトを獲得**
   * プロバイダー別クレジット利用：複数のAIプロバイダーごとのクレジット利用量を比較し、パフォーマンス評価やベンダー最適化・交渉判断などに役立ちます。
   * モデル別クレジット利用：各AIモデルごとの支出を確認し、コストが集中しているモデルの識別や運用価値の評価に繋がります。
   * チャンネル別クレジット利用：コミュニケーションチャネルやワークフローチャンネルごとの利用割合を可視化し、AI活用の主な場面を特定できます。
   * 部門別クレジット利用：部門ごとの消費状況を把握し、予算策定やリソース配分をより合理的に行えます。
   * ユーザー別クレジット利用：個別ユーザーごとの利用量を詳細に追跡することで、主要な利用者やイレギュラーな利用傾向を把握し、効率的な運用を促進します。
