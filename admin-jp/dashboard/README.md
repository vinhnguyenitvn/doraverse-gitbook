# ダッシュボード

## ダッシュボードとは？

ダッシュボードは、組織全体のAIアクティビティを監視・管理するための中心的なハブです。重要なレポートや分析が集約されており、迅速かつデータに基づいた意思決定をサポートします。

## ダッシュボードに含まれるもの：

### [概要](overview.md)

選択した期間における組織のAI利用状況やコストをリアルタイムで要約表示します。

### [ユーザーアクティビティレポート](user-activity-report.md)

組織内ユーザーの利用状況や利用傾向を詳細に把握できます。

### [モデル利用レポート](model-usage-report.md)

各AIモデルの利用状況やコストを分析し、パフォーマンスと支出の最適化を図ります。

### [チャットログ](chat-logs.md)

ワークスペース内の全対話履歴を追跡・確認・管理でき、透明性とコンプライアンスを確保します。
