# AIモデル設定

メイン画面から「アカウント」→「管理」→「AIモデル設定」タブに進みます。

1. 「編集」をクリックして編集モードを有効にします。
2. 各部門ごとに、AIモデルの切り替えトグルをオン／オフして、利用を有効／無効に切り替えます。
3. Doraverseで利用可能なAIモデルと詳細な機能説明を閲覧し、各部門の特性や要件に最適なモデルを選択しましょう。
4. 変更を適用する場合は「変更を保存」、取り消す場合は「キャンセル」をクリックします。

## 💡ヒント

常に最新かつ最適なツールを利用できるよう、AIモデルのアップデート情報を定期的にご確認ください。
