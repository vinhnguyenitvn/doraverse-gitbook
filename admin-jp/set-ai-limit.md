# AI利用上限の設定

## AI利用上限の設定方法

1. メイン画面から「アカウント」→「管理」→「AIモデル設定」タブに進みます
2. 画面右上の「編集」ボタンをクリックして、設定変更を有効にします。
3. クレジット上限の設定
   * **ワークスペースのクレジット上限設定：**\
      組織全体のAI利用コスト管理や予算内運用に役立ちます。希望する一日あたり・一ヶ月あたりのクレジット上限を入力してください。
   * **メンバーごとのクレジット上限設定：**\
      個々のユーザーが許容範囲を超えて利用しないよう細かく管理可能です。各メンバーごとに一日あたり・一ヶ月あたりのクレジット上限を設定します。
4. 「保存」をクリックして設定を適用します。
