# 管理ワークスペースへようこそ



## 管理ワークスペースとは？

Doraverseにおける管理ワークスペースは、管理者が組織全体のユーザー、部門、AIモデル、利用状況を一元的に管理できるコントロールパネルです。これにより、管理者は活動状況のモニタリング、アクセス権限の管理、効率的かつ安全な運用の担保を実現します。

## 管理ワークスペースへのアクセス方法

1. 画面左下の「アカウント」をクリックします。
2. 「管理」を選択します。
3. 管理用に設計された複数のコントロールタブが表示された管理ワークスペースが開きます。

**💡 注意**: 管理ワークスペースは管理者ロールを持つユーザーのみに表示されます。アクセス権については、組織内のDoraverse管理者へお問い合わせください。
